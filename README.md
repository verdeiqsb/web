# VerdeIQ Sdn Bhd - Company Website

A responsive and interactive company website for VerdeIQ Sdn Bhd, featuring multiple pages, animated flows, and queryable project listings.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Multiple Pages**: 
  - Home page with hero section and core domains
  - Organization page with company information and tables
  - Vision & Mission page
  - Projects page with searchable and filterable past projects
- **Interactive Elements**: 
  - Smooth animations and transitions
  - Interactive navigation
  - Search and filter functionality for projects
  - Hover effects and scroll animations
- **GitHub Pages Ready**: Static HTML/CSS/JS files ready for deployment

## Deployment to GitHub Pages

1. Push all files to a GitHub repository
2. Go to repository Settings → Pages
3. Select the branch (usually `main` or `master`)
4. Select the folder (usually `/ (root)`)
5. Click Save
6. Your site will be available at `https://[username].github.io/[repository-name]`

## File Structure

